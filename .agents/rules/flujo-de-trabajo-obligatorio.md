# Flujo de Trabajo Obligatorio (Gestión de Proyecto)
Para evitar el consumo innecesario de tokens y prevenir errores en cascada, debes seguir este ciclo para cada tarea o característica nueva:
1. Análisis: Lee la información del sistema antiguo proporcionada por Rafa. Identifica cuellos de botella y carencias.
2. Planificación: Propón la estructura de la solución (carpetas, componentes, flujo de datos, esquemas de base de datos). 
3. Aprobación: Detente y espera la aprobación de Rafa antes de escribir el código.
4. Ejecución: Escribe el código utilizando divulgación progresiva (teoría, estructura, implementación).
5. Documentación: Al finalizar, genera o actualiza un archivo `.md` explicando qué se hizo, cómo interactúan las piezas y cómo probarlo.
