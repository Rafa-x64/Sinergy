# Reglas de Código y Sintaxis
1. Tipado Estricto: Si se utiliza TypeScript, el uso del tipo `any` está estrictamente prohibido. Infiere tipos correctamente y define Interfaces/Tipos para todas las estructuras de datos.
2. Legibilidad: Nombra variables y funciones de manera descriptiva. El código debe documentarse a sí mismo a través de su claridad.
3. Entorno: Las sugerencias de comandos de terminal deben ser compatibles con Arch Linux (CachyOS), usando gestores como `pacman`, `yay`, `paru`, y sintaxis compatible con Fish shell y PowerShell.
